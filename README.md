# Investify Web Application

Investify is a full-stack financial web application providing stock market insights, company data, financial statements, and personalized watchlists. Built with **React** frontend and **Flask** backend using **PostgreSQL**.

---

## Tech Stack

**Backend:** Flask, Flask-CORS, Flask-SQLAlchemy/SQLAlchemy, PostgreSQL (psycopg2), Werkzeug Security, SMTP (smtplib), yfinance, requests, pandas, numpy, logging, datetime, threading  

**Frontend:** React, react-router-dom, @mui/x-data-grid, Recharts, Framer Motion, Lottie React, React Icons  

---

## Key Features

- User authentication (signup, login, password reset with OTP)  
- Company stock data and financial statements  
- Interactive charts (30-day & long-term history)  
- Personalized watchlist  
- External API integration for live market data
